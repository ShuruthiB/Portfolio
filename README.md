# Shuruthi B - Personal Portfolio

A sleek, modern, and responsive personal portfolio website showcasing my skills, projects, certifications, and experience. Built with a clean aesthetic featuring a built-in dark mode and fully responsive design.

## 🚀 Features

- **Responsive Design**: Looks great on desktop, tablet, and mobile devices.
- **Dark/Light Mode**: Integrated theme toggle to switch between light and dark modes with persistent local storage support.
- **Interactive Elements**: Typewriter effect for roles and smooth scrolling navigation.
- **Project Showcase**: Detailed cards for key projects with links to source code.
- **Resume Download**: Easily accessible direct link to download the latest resume.
- **Contact Details**: Integrated quick links to LinkedIn, GitHub, and email.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling, grid/flexbox layouts, responsive media queries, and CSS variables for theme management.
- **Vanilla JavaScript**: Dynamic interactions, theme toggling, and typewriter effects.
- **Tabler Icons**: Lightweight icon library for UI elements.

## 📁 Repository Structure

```
portfolio_v2/
├── index.html          # Main HTML structure
├── style.css           # Styling and dark mode logic
├── script.js           # Interactive scripts (theme toggle, typewriter, etc.)
├── profile.jpg         # Personal profile image
├── Shuruthi_B_Resume.pdf # Downloadable resume file
└── README.md           # Project documentation
```

## ⚙️ Getting Started

To view the portfolio locally:

1. Clone this repository (or download the ZIP).
2. Navigate to the project directory.
3. Open `index.html` in your preferred web browser. No local server or build steps are required.
